How NextStep Processes Erasure

Unlike services that simply “soft-delete” or mark records as hidden, NextStep conducts hard deletions:

  • Database Collections: User profiles, hashed passwords, assessment scores, and activity records are removed from MongoDB.
  • Uploaded Evidence Files: Attached PDF, code, and document files are removed from disk using secure unlinking.
  • Session Cryptography: Active tokens are invalidated immediately, revoking all open browser cookies.
