# Career Profile: Data Analyst

A Data Analyst examines complex datasets to identify trends, draw meaningful conclusions, and produce actionable business intelligence dashboards for decision-makers.

## Required Technical Skills
- **SQL (Structured Query Language)**: Writing complex JOINs, window functions, aggregations, and subqueries across relational databases (PostgreSQL, BigQuery).
- **Python or R**: Data manipulation using Pandas, NumPy, and basic data cleaning pipelines.
- **Data Visualization & BI Tools**: Building interactive dashboards using Power BI, Tableau, or Metabase.
- **Descriptive and Inferential Statistics**: Hypothesis testing, mean/median distributions, variance, and correlation analysis.
- **Excel / Google Sheets**: Pivot tables, VLOOKUP/XLOOKUP, and business modeling.

## Required Soft Skills
- Business acumen and stakeholder communication.
- Translating numbers into compelling narrative stories.
- High attention to data integrity and anomaly detection.

## Recommended Certifications
- Google Data Analytics Professional Certificate
- Microsoft Certified: Power BI Data Analyst Associate (PL-300)
- AWS Certified Data Analytics - Specialty

## Career Roadmap
1. Master advanced SQL queries and relational database concepts.
2. Learn Python data manipulation libraries (Pandas, Matplotlib, Seaborn).
3. Build 2-3 end-to-end dashboard projects answering specific business questions.
4. Publish interactive reports on Tableau Public or GitHub with business insights.
5. Target entry-level Business Intelligence or Junior Data Analyst roles.
